# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.5.x   | ✅ |
| < 0.5   | ❌ |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report vulnerabilities by opening a [GitHub Security Advisory](https://github.com/n0rm4l-me/kmorph/security/advisories/new).

We aim to respond within 72 hours and release a patch within 14 days for critical issues.
